# Car-Animation
🚗 A simple car animation project built using HTML and CSS, featuring a moving sky, trees, track, animated wheels, and a fixed car to create a realistic driving effect.

## ✨ Features

- 🚗 Fixed car animation
- 🛞 Rotating car wheels
- 🌤️ Moving sky/background
- 🌳 Moving trees
- 🛣️ Moving road/track
- 🎨 Simple 2D animation

## 🛠️ Technologies Used

- HTML5
- CSS3
- Javascript
